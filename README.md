## How it works (the idea behind it)

1. **Collect** real exam questions from past papers.
2. **Sort** them by topic (Matter, Heat, Plant Systems…) — *spotting patterns*.
3. **Pick** the questions that come up the most often — the ones worth studying.
4. **Build** a tidy cheat sheet for each topic, with the question pictures included.

So instead of flipping through dozens of papers, you get one clear page per topic.
That's *breaking a big problem into smaller steps* and letting the computer do the
boring, repetitive part! 🧠

> 📂 This repo holds the **finished cheat sheets** (the output). The screenshots in
> `screenshots/` are the exam-question pictures the cheat sheets point to.
